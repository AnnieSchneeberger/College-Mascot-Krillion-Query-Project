This folder will hold all of the data used in my final project.

The "Krillion_Data_Project.xlsx" is my current cleaned data sheet. Each field is pretty self explanatory, but here is the breakdown to be extra thorough:

"University" - The full name of the university.
"State" - The state in which the university is located. 
"Wikipedia URL" - The link to the university's Wikipedia page that I used to scrape its mascot data from.
"Mascot" - The name of the mascot listed in the infobox on the university's Wikipedia page.
